Live Video Call Relay (TURN) 

    
Live video calls between an executive and a customer connect directly when possible. On many mobile networks (Jio, Airtel, Vi) a direct connection fails and the call needs a relay (TURN server). Recommended: Cloudflare Realtime TURN — create a TURN key in the Cloudflare dashboard (Realtime → TURN Server) and paste the Key ID and API token here. Or enter any TURN server with fixed credentials.
