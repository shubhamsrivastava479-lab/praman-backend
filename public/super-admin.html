Evidence Storage

By default, WhatsApp photos, documents, and call recordings save to this server's local disk — most hosts (including Render's free tier) wipe this on restart or redeploy. Connect S3-compatible object storage (Cloudflare R2 recommended — cheap, no egress fees) so evidence is never lost.

Live Video Call Relay (TURN)

Live video calls between an executive and a customer connect directly when possible. On many mobile networks (Jio, Airtel, Vi) a direct connection fails and the call needs a relay (TURN server). Recommended: Cloudflare Realtime TURN — create a TURN key in the Cloudflare dashboard (Realtime → TURN Server) and paste the Key ID and API token here.
